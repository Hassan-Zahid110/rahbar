# AI Usage Disclosure

In accordance with Section 8 of the RAHBAR specification ("AI assistance: the rule is honest attribution, not avoidance"), this document records every AI tool used during development, what it generated or shaped, and what we verified, modified, or tuned afterward.

| Tool | What it wrote or shaped | What we changed afterwards, and why |
| --- | --- | --- |
| **Google Antigravity (Gemini)** | Assisted with scaffolding the five indexing pipeline stages (`extract.py`, `clean.py`, `chunk.py`, `embed.py`, `store.py`), the eight-step FastAPI query pipeline (`answer.py`, `cache.py`, `grounding.py`, `prompting.py`, `chroma.py`), `OllamaProvider` / `HostedProvider` HTTP clients, Kubernetes base/overlay manifests (`k8s/`), and GitHub Actions CI/CD workflows (`.github/workflows/ci.yml`, `cd.yml`). | 1. **Zero-downtime re-index semantics (`indexer/pipeline/store.py`)**: Replaced naive `delete_collection` recreation with in-place batched `upsert` + stale-ID pruning when `embed_model` and `dimension` match so concurrent API requests never hit an empty collection during `CronJob/reindex` runs.<br>2. **Immutable Job spec fix in CD (`cd.yml`)**: Removed post-creation `kubectl set volume` on a running Job (rejected by Kubernetes API immutability rules) and moved volume wiring into Kustomize patches (`k8s/overlays/ci`).<br>3. **Section-heading detection (`indexer/pipeline/chunk.py`)**: Refined heading regexes with length (`<= 85` chars) and trailing-period guards so numbered prose clauses (`1.1 A student must attend...`) are not misclassified as standalone section headers.<br>4. **Empirical parameter calibration (`k8s/base/configmap.yaml`, `docs/PIPELINE.md`)**: Replaced initial placeholder `CHUNK_SIZE`, `CHUNK_OVERLAP`, `CACHE_THRESHOLD`, `RELEVANCE_FLOOR`, and container CPU/memory requests & limits with values measured directly against `eval/golden.yaml` and `kubectl top pods` on Minikube. |
